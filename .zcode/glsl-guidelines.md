# GLSL Guidelines

本文件维护 GLSL 视觉、接口和源码规则。

## 技术要求

- 严禁立即模式 `glBegin`/`glEnd`

## 最高视觉要求

- 形状必须狂野，亮度必须刺目，颜色必须具有攻击性，整体风格必须极端。
- 子元素不得弱于主体，其视觉强度必须与主体处于同一级别。
- 每个子元素必须同时具备充分的高频与低频细节，并在 2 倍放大下保持清晰。
- 实现路径必须优先保证效果与细节完整，性能、复用和维护成本均不得降低视觉要求。

## GLSL 着色器

### 编译规则

- 版本声明必须统一为 `#version 430`。
- 源码严禁出现注释，当前编译链无法接受注释。
- `active`、`sample` 等保留字严禁用作自定义名称。
- 除 `main` 外，函数体首行严禁留空。

### 视觉模型

- 噪声、扰动、遮罩与采样必须连续，任何分段噪声都严禁使用。
- 纹理内部的形状、亮度、颜色、透明度与遮罩必须平滑过渡，严禁硬边。
- 距离和角度方向上严禁固定间距的分段效果。
- 方向必须来自位置、主体状态、法线、速度或稳定几何；时间只能推进演化，严禁生成单一方向。
- 每个元素必须通过透明度或尺寸完成渐出，并具备噪声或纹理驱动的动态。
- 视觉参数必须按实际像素规模评估；变量参数必须追溯到来源。

### 坐标与命名

- 常量使用 `UPPER_SNAKE_CASE`，名称必须表达视觉职责，目标长度不得超过 28 字符。
- 函数与局部变量使用 `camelCase`。
- 坐标名称固定为：输入 `fragUV`、归一化 `uv`、中心化 `localUv`、宽高比修正 `aspectUv`。
- 轴向量使用 `axis`，横向量使用 `crossAxis` 或 `signedCrossAxis`。
- 半径使用 `radius` 或 `*Radius`，距离使用 `dist` 或 `*Dist`。
- 阶段进度、颜色汇总和最终透明度分别使用 `progress`、`color`、`alpha`。
- 文件名、uniform、varying、sampler 与 render pass 必须保持外部绑定名称。
- 同类阈值、宽度、羽化、alpha、速度和强度必须保持相同命名粒度。

### 片元流程

- `main()` 的固定顺序是坐标、几何标量、场或遮罩、颜色、透明度、discard、输出。
- texture pass 的固定顺序是采样、透明度、discard、输出。
- 坐标必须先于所有依赖它的场、遮罩与采样计算；颜色汇总必须先于最终 alpha。
- 候选片元明显过量时必须先按视觉边界粗剪枝，但严禁削弱最高视觉要求。
- 单独计算 alpha 的 pass 必须在输出前执行 `alpha < 0.001` 的 discard。

### 函数边界

- helper 只能承载完整视觉场、遮罩或合成步骤，严禁包装单个简单公式。
- 通用工具函数必须是纯计算。
- 视觉场函数必须返回强度、颜色或合成结果，参数名必须对应调用方的真实视觉语义。

### 数值来源

- 颜色必须来自外部颜色、纹理或具名模型，严禁硬编码。
- 大区域参数必须使用整数、半数、十分位、二十分位或推导值，严禁无来源的精碎小数。
- 小数细节只允许用于噪声、hash、epsilon、AA、采样偏移和局部扰动，严禁控制半径、时间、alpha、主遮罩、主羽化或 pass 强度。
- 同一细节场的小数必须保持相近粒度，严禁随机碎片化。
- 关键调参值必须命名；`0.0`、`0.5`、`1.0`、`2.0` 等归一化构造值允许内联。
- 数学常数、hash 常数、epsilon、render pass 和多处复用值必须声明为 `const`。
- 严禁为消除裸数值而制造低语义常量清单。
- 无特殊数学意义的数值严禁保留 3 位或更多小数；数学常数、hash 与 epsilon 允许高精度。

### Java 与 GLSL 边界

- 一个视觉参数只能有一个所有者，Java 与 GLSL 严禁重复定义。
- frag 严禁读取外部尺度，所有视觉尺度必须在 shader 内归一化生成。
- 输入只允许包含渲染边界、实体状态、纹理、颜色和无法可靠内生的运行状态。
- 半径比例、阶段曲线、遮罩、羽化、强度与局部细节全部归 GLSL 所有。
- 时间由 Java 提供，只允许驱动演化，GLSL 严禁用它判定阶段或自行定义时间。
- Java 只负责包围范围、生命周期、图层、blend、位置和外部状态。
- 跨边界数值必须有明确理由；否则必须只存在于 GLSL。
- 已绑定的 uniform location 以及 vertex/fragment 连接变量必须保持名称一致。

### 输出契约

- 输出变量固定为 `fragColor`。
- 写入前必须完成最终颜色与 alpha。
- 颜色只能来自当前 pass 的颜色源、采样或合成；alpha 只能来自遮罩、采样 alpha、阶段 alpha 或外部 alpha 乘数。
